# CriticJEPA project page

Research homepage for *CriticJEPA: World Models Are Better Critics Than Optimizers*. Plain HTML, CSS, and JavaScript. GitHub Pages serves the root of `main`.

- `assets/maze/` holds official Visual AntMaze tasks (H-JEPA settings, 350-step budget, seed-42 frozen model) re-run for both planners with per-step joint states recorded, then re-rendered top-down over the full maze. Left: H-JEPA. Right: CriticJEPA.
- `assets/clips/` holds Push-T and Cube rollouts, left H-JEPA and right CriticJEPA, one video frame per environment step.
- Charts are drawn from numbers in the paper. The method animation is a labeled schematic.
- Tsinghua University and Manifold AI marks come from the HandWorldBench project; the authors provided the Zhongguancun Academy seal. Inter and Newsreader are distributed under the licenses in `assets/`.
