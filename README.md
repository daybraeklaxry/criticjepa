# CriticJEPA project page

The research homepage for *CriticJEPA: World Models Are Better Critics Than Optimizers*. The site is plain HTML, CSS, and JavaScript. GitHub Pages serves the root of `main`.

The interactive charts show measured AntMaze results from the paper. The method schematic and refinement figure come from the manuscript. The Tsinghua University and Manifold AI marks come from the [HandWorldBench project](https://embodiedcity.github.io/HandWorldBench/). The authors provided the Zhongguancun Academy seal.
