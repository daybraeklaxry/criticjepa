# CriticJEPA project page

The research homepage for *CriticJEPA: World Models Are Better Critics Than Optimizers*. The site is plain HTML, CSS, and JavaScript. GitHub Pages serves the root of `main`.

The charts show measured AntMaze results from the paper, and the method schematic comes from the manuscript. The Tsinghua University and Manifold AI marks come from the [HandWorldBench project](https://embodiedcity.github.io/HandWorldBench/). The authors provided the Zhongguancun Academy seal. The locally hosted Inter and Newsreader fonts are distributed under the licenses in `assets/`.
